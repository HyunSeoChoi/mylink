# MyLink

MyLink is a simple Linktree-style profile page built for the week 1-3 practice project.

## Features

- Personal profile section with name and short introduction
- Link buttons for Instagram, Blog, and Portfolio
- Responsive layout for mobile and desktop screens
- Git and GitHub ready project structure

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
